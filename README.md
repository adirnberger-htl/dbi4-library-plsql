# DBI4 Library Database (Oracle PL/SQL)

Enterprise relational library database schema, PL/SQL stored procedures & integrity triggers.

## Contents
- `library.sql`: Relational schema definitions with constraints and foreign keys.
- `library_procedures.sql`: PL/SQL stored procedures and packages for library transactions.
- `library_full_insert.sql`: Seed data for realistic testing and verification.
- `trigger-test.sql` & `test.sql`: Automated verification scripts for constraints and triggers.
- `util/create_user.sql`: Database user creation and privilege grants.
